# Навигатор

Небольшое Flutter Web-приложение на Яндекс Картах: показывает текущую геопозицию, позволяет выбрать финиш нажатием на карту и строит автомобильный маршрут.

## Запуск

Установите Flutter с поддержкой Web и получите API-ключ JavaScript API Яндекс Карт. В консоли Яндекса ограничьте ключ разрешёнными доменами приложения; ключ, используемый в браузере, виден пользователям.

```sh
flutter pub get
flutter run -d chrome --dart-define=YANDEX_MAPS_API_KEY=ваш_ключ
```

Для production-сборки передайте тот же define:

```sh
flutter build web --dart-define=YANDEX_MAPS_API_KEY=ваш_ключ
```

Геолокация браузера работает на `localhost` и по HTTPS. Нажмите кнопку геопозиции, затем выберите финиш на карте и постройте маршрут.
